# SkyrimPlatform2

SkyrimPlatform2 (SP2) is Skyrim Underground's SKSE plugin for running TypeScript-authored scriptsinside Skyrim, and later for hosting the in-game browser overlay. It replaces the upstream skymp SkyrimPlatform for Skyrim Underground and is written as a general modding platform, built to Skyrim Underground's needs first. It does not promise to run existing SkyrimPlatform mods, and it needs no Node.js on the player's machine: scripts run in an embedded JavaScript engine.
